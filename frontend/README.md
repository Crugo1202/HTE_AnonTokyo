# Frontend (Vite)

React web app built with Vite. Upload and analyze teacher performance.

## Run

```bash
npm install
npm run dev
```

Open http://localhost:5173/

- `npm run build` — production build
- `npm run preview` — preview production build
- `npm run start` — Express server + Vite (for upload API)

The Expo/React Native app lives in **`../frontend-expo/`**.
